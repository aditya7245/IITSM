# Test case catalogue

The test cases of I-ITSM, each tied to the automated test that checks it. Test names are written as ClassName#methodName and live under `backend/src/test/java/com/iitsm/`. All automated tests run with `mvn clean verify` from `iitsm/backend`.

Users and data come from the dev seed data (password `Password@123`): `emp1` Asha and `emp2` Ravi are employees, `tech1` Kiran (Application Support) and `tech2` Sana (Infrastructure) are technicians, `lead.app` Meera is a team lead, `admin` and `manager` are administrators. A payment outage (impact 3, urgency 3, Payment Application with criticality 5) scores 45 and is P1.
